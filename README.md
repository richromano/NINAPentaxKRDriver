# PentaxKR Camera Plugin

You can install the plugin from the NINA PlugIn tab.

Make sure your camera is in MSC mode.

The software supports both Manual and Bulb modes.  No other modes are supported.  The software will check to make sure it is in one of the two modes during connection.  Once connected disconnect before switching modes since the software does not check for mode changes once it is connected. When in Bulb mode make sure it is not in timer setting but in true Bulb mode.

There is an Aperture window in the Imaging tab.  This allows changing the Aperture.  You can press Refresh and the driver will rescan the available Apertures in the current lens.

There is a manual in the releases section.
